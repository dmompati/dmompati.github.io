# Dessie Mompati — Portfolio

Human-centred design, workshop facilitation, service design and UX/UI work.

Live website: https://dmompati.github.io/

## Website files

- `index.html`: homepage, selected work, approach, about and contact.
- `projects/`: five current case studies.
- `.nojekyll`: serves the site as plain static HTML on GitHub Pages.

Each page includes its own styles, scripts, images and résumé download. The site does not depend on UXfolio or the previous Bootstrap template.

GitHub Pages publishes the `master` branch from the repository root. Changes to these files are deployed automatically.
